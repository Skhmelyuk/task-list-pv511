# 📋 Task List App (`task-list-pv511`)

Застосунок списку завдань (Task List) на базі **React 19**, **TypeScript** та **Vite** з глобальною стилізацією, декомпонований на чисті та незалежні компоненти відповідно до **Інструкції №1 (Урок 7)**.

---

## 🏗️ Компонентна архітектура проєкту

```text
src/
├── types/
│   └── index.ts          # Моделі даних: Task, Priority
├── components/
│   ├── Header.tsx        # Шапка додатку з іконкою та заголовком
│   ├── TaskForm.tsx      # Форма додавання: інпут, селект пріоритету, дедлайн, кнопка
│   ├── Counter.tsx       # Панель статистики (всього, в процесі, виконано, прогрес-бар)
│   ├── TodoList.tsx      # Контейнер списку завдань та стан порожнього списку (Empty State)
│   └── TodoItem.tsx      # Картка окремого завдання (пріоритети, чекбокс, видалення)
├── App.tsx               # Кореневий компонент-оркестратор
├── index.css             # Єдиний файл глобальних стилів
└── main.tsx              # Точка входу в застосунок
```

---

## 🚀 Команди для запуску

1. `npm install` — встановлення залежностей
2. `npm run dev` — запуск локального dev-сервера
3. `npm run build` — збірка проєкту
4. `npm run lint` — перевірка лінтером Oxlint
