# 📋 Task List App (`task-list-pv511`)

Базова структура та стилізація застосунку списку завдань (Task List) на базі **React 19**, **TypeScript** та **Vite** з використанням глобальних стилів. Весь код розміщено в єдиному компоненті **`src/App.tsx`** без розбиття на окремі файли компонентів.

---

## 🏗️ Структура проєкту

```text
src/
├── App.tsx          # Повна розмітка структури: типи, Header, TaskForm, Counter, TodoList, TodoItem
├── index.css        # Єдиний файл глобальних стилів (скидання, змінні палітри, оформлення карток)
└── main.tsx         # Точка входу в застосунок
```

---

## 🎨 Що містить розмітка в `src/App.tsx`:

1. **Типізація**: інтерфейс `Task` та тип `Priority` (`low` | `normal` | `high`).
2. **Шапка (`.app-header`)**: назва «Task List», підзаголовок та іконка.
3. **Форма додавання (`.task-form`)**: текстове поле, селект пріоритету, вибір дедлайну, кнопка «＋ Додати».
4. **Панель статистики (`.counter`)**: картки «Всього», «В процесі», «Виконано» та горизонтальний прогрес-бар.
5. **Список завдань (`.todo-list`)**: картки завдань із різними пріоритетами, бейджами, дедлайнами, чекбоксами та кнопкою видалення `🗑️`, а також стан порожнього списку.

---

## 🚀 Команди для запуску

1. `npm install` — встановлення залежностей
2. `npm run dev` — запуск локального dev-сервера
3. `npm run build` — збірка проєкту
4. `npm run lint` — перевірка лінтером
